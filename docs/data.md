### Merged-2D Dataset Construction

The Merged-2D dataset is constructed by:
1. Combining structures from C2DB and 2DMatPedia
2. Filtering to retain only 2D slab structures (single-layer or few-layer)
3. Removing duplicates based on structure similarity
4. Splitting into training (80%), validation (10%), and test (10%) sets

**Final dataset size: 17,654 filtered structures**

## How DFCA Uses the Data

The Merged-2D dataset is used for:

1. **Training:** Crystal structures in `Data/train.csv` train the CrystalDiT model
2. **Validation:** Structures in `Data/val.csv` validate during training
3. **Testing:** Structures in `Data/test.csv` evaluate final model quality

### Data Format

```csv
material_id,formation_energy_per_atom,dft_band_gap,pretty_formula,e_above_hull,elements,cif,spacegroup_number,...
```

### Preprocessing

Raw C2DB/2DMatPedia data is preprocessed using `dfca/data/preprocessing.py` to:
- Filter 2D slab structures
- Extract lattice and atomic coordinates
- Generate DFCA tensor representation
- Create train/val/test splits

## Obtaining the Data

To reproduce DFCA training:

### C2DB
1. Visit https://cmr.fysik.dtu.dk/c2db/c2db.html
2. Download the C2DB dataset (requires registration)
3. Follow preprocessing instructions in `dfca/data/preprocessing.py`

### 2DMatPedia
1. Visit http://www.2dmaterials.org/
2. Download the 2DMatPedia dataset
3. Apply the same preprocessing steps

### Dataset Merging and Filtering
1. Combine structures from both sources
2. Apply 2D filtering criteria (vacuum thickness, connectivity, etc.)
3. Remove duplicates using structure similarity
4. Generate train/val/test splits (recommended: 80/10/10)
